What is a Static Website?

A static website is made of fixed files: HTML, CSS, and images. Every visitor sees the same content. There is no database and no server-side code running per visitor.

Analogy: a static website is like a printed poster. Everyone who looks at it sees the same thing.

What is Static Hosting?

Hosting means storing your website files on a computer in the cloud that is always online, so anyone can open your site using a link.

Analogy: hosting is like renting a spot on a public notice board for your poster.

Static vs Dynamic

Static: same page for everyone (portfolio, blog, documentation).
Dynamic: page changes per user and uses a database (Facebook, online banking).

Benefits of Static Hosting

  • Cheap or free: platforms like GitHub Pages host static sites at no cost.
  • Fast: files are simply sent, with no processing.
  • Secure: no database or server code means fewer things to attack.
  • Scalable: it handles many visitors easily.

CDN (Content Delivery Network)

A CDN keeps copies of your files in many cities, so visitors load the site from the closest copy.

Analogy: photocopies of your poster placed in many cities.

How I Hosted This Site

  1. Created the website file (index.html).
  2. Created a GitHub repository.
  3. Uploaded the file to the repository.
  4. Enabled GitHub Pages in the settings.
  5. GitHub gave me a public link, and the site went live.
